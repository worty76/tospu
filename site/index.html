How to contribute Read the sprite guide

  1. Draw or generate a sprite sheet

    Four strips on a flat magenta background: idle, wave, cheer and sleep. The guide includes a ready-made prompt.

  2. Slice it into a pack

    The slicer cuts the frames, removes the background and writes the manifest.

    python3 tools/slice_sprites.py my-buddy.png \
  --id my-buddy --name "My Buddy" --out sprites

  3. Open a pull request

    Add your folder under sprites/. Please share only art you made or have permission to share.

Questions

Something else? Open an issue on GitHub.

Is Tospu free?

Yes. Download it from the releases page, or build it yourself from the source on GitHub.

Which computers does it run on?

macOS today. The code is written with Windows and Linux in mind, and those builds are on the way.

Does it send my messages anywhere?

No. Your messages and settings are plain files in a folder on your Mac. The only network request is the update check, and only when you ask for it.

Will it pop up during my meeting?

Set quiet hours, or press ⌘ ⇧ Y to turn on quiet mode so only “Keep going.” shows. Either way it never steals focus.

Can I write messages in my own language?

Yes. Messages can be in any language, accents and emoji included.
